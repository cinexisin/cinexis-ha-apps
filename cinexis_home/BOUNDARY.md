# `cinexis_home` — the ordinary owner-facing app

## What it does

Enrolment, local Home Assistant integration, WABot connectivity, health, and the
ingress UI. Everything an owner needs, and nothing more.

## What it must never contain

| Excluded | Why |
|---|---|
| `frpc` | A tunnel client is remote-access machinery. The everyday app has no business carrying one |
| Remote shell / command execution | Nothing in the owner path needs it, and it is the single largest privilege a support tool has |
| Host-control credentials | It controls nothing on the host |
| Support identity material | Support identity belongs to the support app, and to a session the owner approved |
| Docker socket | Hands over the whole host |
| `hassio_api` | The Supervisor API can install, update and remove other add-ons |
| `map: config` / `map: share` | It reads Home Assistant through the API and keeps its own state in `/data` |
| Published ports | Ingress only; nothing on the home network reaches it |
| Any scanned-session WhatsApp library | Not in the owner app, directly or transitively |

## Why the split

Folding Remote Support in would widen the everyday app's privileges and
dependency graph for a capability most owners use rarely or never. The app that
runs in every house all the time should be the one with the smallest reach.

`ENFORCED_SEPARATION.json` is generated by a machine check, not by this document.
