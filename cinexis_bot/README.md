# Cinexis Smart Home Bot

Home automation through WhatsApp and Telegram, running inside your Home Assistant. Control devices, scenes and schedules from chat; give each person their own permissions; get door and gate notifications with snapshots; a daily report; the CINEXIS round dashboard as a package. Local control never depends on the internet, the cloud or a licence.

Full documentation is in the add-on's Documentation tab. Support: support@cinexis.cloud · https://cinexis.cloud/support
